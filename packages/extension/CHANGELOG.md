# Changelog

## v0.0.1
- **Spreadsheet Editing UI**: Added inline cell updates directly inside query result tables.
- **Dynamic SQL Script Generator**: Instantly compile spreadsheet changes to ANSI/MySQL update query scripts.
- **Copy SQL Script Button**: Convenient click-to-copy button for update query scripts in the footer panel.
- **Automatic Data Refresh**: Query tables automatically reload on successful modifications.
- **Native Key Constraints Overrides**: Direct system catalog queries for primary keys on MySQL, PostgreSQL, SQLite, and MSSQL databases.
