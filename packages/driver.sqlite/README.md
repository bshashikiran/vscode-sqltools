# VSCode DataGrip - SQLite Driver

This extension adds SQLite database connection support to **VSCode DataGrip**.

> [!NOTE]
> This extension is a custom fork of the open-source [SQLTools SQLite Driver](https://github.com/mtxr/vscode-sqltools/tree/dev/packages/driver.sqlite) and is bound to the rebranded **VSCode DataGrip** core extension.

## Features

- Connects to local and relative SQLite database files.
- Enables spreadsheet-like cell updates and write-backs.
