# VSCode DataGrip - MySQL/MariaDB Driver

This extension adds MySQL, MariaDB, and TiDB database connection support to **VSCode DataGrip**.

> [!NOTE]
> This extension is a custom fork of the open-source [SQLTools MySQL/MariaDB Driver](https://github.com/mtxr/vscode-sqltools/tree/dev/packages/driver.mysql) and is bound to the rebranded **VSCode DataGrip** core extension.

## Features

- Connects to MySQL, MariaDB, and TiDB instances.
- Enables spreadsheet-like cell updates and write-backs.
