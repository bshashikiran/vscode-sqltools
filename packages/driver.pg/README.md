# VSCode DataGrip - PostgreSQL Driver

This extension adds PostgreSQL and CockroachDB database connection support to **VSCode DataGrip**.

> [!NOTE]
> This extension is a custom fork of the open-source [SQLTools PostgreSQL Driver](https://github.com/mtxr/vscode-sqltools/tree/dev/packages/driver.pg) and is bound to the rebranded **VSCode DataGrip** core extension.

## Features

- Connects to PostgreSQL and CockroachDB instances.
- Enables spreadsheet-like cell updates and write-backs.
