# VSCode DataGrip - SQL Server Driver

This extension adds Microsoft SQL Server and Azure SQL database connection support to **VSCode DataGrip**.

> [!NOTE]
> This extension is a custom fork of the open-source [SQLTools MS SQL Server Driver](https://github.com/mtxr/vscode-sqltools/tree/dev/packages/driver.mssql) and is bound to the rebranded **VSCode DataGrip** core extension.

## Features

- Connects to MS SQL Server and Azure SQL instances.
- Resolves key constraints and tables.
